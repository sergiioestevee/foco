# CLAUDE.md — Karpathy Style

## 1. Guiding Principles
- **Think First:** Understand the problem, explain your approach in 1-2 sentences before writing any code.
- **Simplicity:** Choose the simplest functional implementation. Avoid over-engineering and bloated abstractions.
- **Surgical Changes:** Keep edits minimal. Fix exactly what is needed without breaking or refactoring unrelated lines.
- **Test-Driven Intent:** Define how to test the change or write a fast script to verify it immediately.

## 2. Command Reference
- Use `/brainstorm` to dump chaotic thoughts into an organized breakdown.
- Use `/write-plan` to split big tasks into tiny, bite-sized checklists.
- Use `/execute-plan` to run steps sequentially while avoiding distractions.
